# 🦉 آموزگار هوشمند ریاضی سوم دبستان (Smart Math Tutor)

پلتفرم تعاملی آموزش و یادگیری مفهومی ریاضی پایه سوم ابتدایی ایران بر پایه هوش مصنوعی مولد (Google Gemini)، روش تدریس سقراطی، گیمیفیکیشن و بانک سوالات پویا.

---

## 🌟 قابلیت‌های کلیدی سامانه

1. **گفتگو و تدریس سقراطی با «استاد دانا» (AI Socratic Tutor):**
   - آموزش تعاملی گام‌به‌گام منطبق بر سرفصل‌های رسمی کتاب درسی ایران.
   - **پایبندی به روش سقراطی:** هدایت کودک با طرح سوالات تک‌مرحله‌ای جهت رسیدن به پاسخ.
   - **اعتبارسنجی محاسباتی:** رصد خروجی‌های مدل، تصحیح خودکار اشتباهات حسابی احتمالی و تبدیل ارقام لاتین به فارسی.

2. **حل هوشمند مسئله از روی دست‌خط و تصویر کتاب (Vision OCR Solver):**
   - امکان بارگذاری یا گرفتن عکس از تمرین‌های کتاب ریاضی با دوربین گوشی یا تبلت جهت تحلیل و ارائه راه‌حل مرحله‌به‌مرحله.

3. **مدل اشتراک و دسترسی کاربران:**
   - **نسخه رایگان:** ۷ سوال هوش مصنوعی روزانه + دسترسی کامل به فصل‌های ۱ و ۲ کتاب (الگوها و شمارش، ارزش مکانی) و بازی‌های مربوطه.
   - **اشتراک طلایی (VIP):** دسترسی نامحدود به تمامی ۸ فصل کتاب، بازی‌های تعاملی و پرسش و پاسخ نامحدود با هوش مصنوعی در طول مدت اشتراک.
   - **بسته ۵۰ سوال اضافه:** اعتبار ۵۰ سوال هوش مصنوعی بدون تاریخ انقضا.
   - **وضعیت پرداخت:** سیستم درون‌برنامه‌ای برای کافه بازار، مایکت و درگاه وب آماده‌سازی شده است (به زودی فعال می‌شود)؛ در حال حاضر امکان فعال‌سازی تست اشتراک توسط اولیا / ادمین وجود دارد.

4. **بازی‌های تعاملی آموزشی برای ۸ فصل (Interactive Manipulatives):**
   - ابزارهای دست‌ورزی مجازی برای مفهوم کسر، ساعت عقربه‌ای، بازی جدول ضرب، الگوهای عددی، آمار، ارزش مکانی و مساحت/محیط.

5. **دفترچه هوشمند اشتباهات (Smart Mistake Notebook):**
   - ثبت اشتباهات کودک در حل کوئیزها و پیشنهاد تمرین مجدد سوالات چالش‌برانگیز.

6. **همگام‌سازی ابری و امنيت کودکان (COPPA-Ready):**
   - ورود با شماره موبایل و ذخیره امن اطلاعات در سمت سرور.
   - قفل دسترسی اولیه جهت تأیید رضایت‌نامه اولیا.

## ⚙️ متغیرهای محیطی (Environment Variables)

برای اجرای محلی، فایلی به نام `.env` بر اساس نمونه زیر ایجاد کنید:

```env
# ۱. کلید سرویس هوش مصنوعی Google Gemini (الزامی)
GEMINI_API_KEY=AIzaSy...

# ۲. کلید امنیتی ادمین جهت فعال‌سازی تست و مدیریت (پیش‌فرض: ostad_admin_secret_123)
ADMIN_SECRET=ostad_admin_secret_123

# ۳. کلید درگاه پیامک کاوه‌نگار برای ورود با شماره موبایل (اختیاری؛ حالت دمو در صورت نبود)
KAVENEGAR_API_KEY=your_kavenegar_api_key_here

# ۴. متغیرهای اتصال به Vercel KV / Upstash Redis (اختیاری)
KV_REST_API_URL=https://your-kv-instance.upstash.io
KV_REST_API_TOKEN=your_kv_rest_token_here

# ۵. پورت اجرای سرور
PORT=3000
NODE_ENV=development
```

---

## 🚀 نحوه نصب و اجرای محلی

1. کلون کردن مخزن و نصب وابستگی‌ها:
   ```bash
   npm install
   ```
2. تنظیم فایل `.env` با کلیدهای موردنیاز.
3. اجرای سرور توسعه (همراه با کلاینت Vite و سرور Express):
   ```bash
   npm run dev
   ```
4. دسترسی به برنامه در مرورگر: `http://localhost:3000`
